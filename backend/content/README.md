## Note Standards

Every note includes:
- Learning objectives
- Intuition and motivation (no assumed background)
- Core concept (progressive from simple to complex)
- Worked example with step-by-step trace
- Python implementation (syntactically verified)
- Java implementation
- Complexity analysis (time and space, all cases)
- Common mistakes
- Real-world applications
- Key takeaways (5 bullet summary)
- Knowledge check (4 questions with answers where indicated)
